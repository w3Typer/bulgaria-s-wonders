# Bulgaria's Wonders

Create only front-end of a multi-page website about facts for Bulgaria, do not do BE. Use HTML, CSS and vanilla JS only. 
The main page should have:
- header with a logo and h1 (Bulgaria)
- left section with a vertical menu with 12 topic names 
- main part with 3 sentences about Bulgaria shown as ul with interesting bullet signs (s.th. connected with Bulgaria - rose / embroidery / )
- footer copyright-sign 2026 | OneDev | All Rights Reserved
Each menu link opens a new page with header, menu, footer, main information. The text in the Header is the same as in the menu link.
- all pages have responsive design; when in small screen - the menu goes before the main section
- the info in each page is shown as separate cards with width = whole section width
